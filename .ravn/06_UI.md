# UI — Marca y estándar

## Marca

- Blanco `#f2efe8` + negro `#070707`. **CERO color** (el verde/rojo solo donde
  el dato lo exige: saldos, alertas).
- Tipografía **Raleway** (cargada local en `src/app/raleway-local.ts`).
- **Cero border-radius.** Logo: `RAVN.` (componente `src/components/ravn-logo.tsx`).
- El estatus se muestra, no se dice: nunca "premium" ni "Zona Norte" en copy.
- Estilo: minimalista, arquitectónico, austeridad elegante.

## Stack obligatorio para toda UI nueva

1. Invocar el skill **`ui-ux-pro-max`** antes de diseñar o implementar.
2. Animaciones y transiciones con **Framer Motion** (no CSS animations puras).
3. En landings: hero con referencia de **21st.dev**.
4. Mobile primero en la app: Eze la opera desde el celular en obra.

## Patrones existentes (seguirlos, no reinventar)

- Tarjetas y modales: `src/components/cashflow-*-modal.tsx`, `crear-item-catalogo-modal.tsx`.
- Documentos A4 de cara al cliente: `src/components/plantilla-a4-virtual.tsx`,
  `informe-mo-print.tsx`, `certificado-conformidad-print.tsx` — HTML negro A4,
  importe/precio grande, PDF vía Chrome headless.
- Shell y navegación: `src/components/shell/`, cockpit: `src/components/cockpit/`.
- Primitivas: `src/components/ui/` — buscar acá antes de crear un control nuevo.
- Panel `/dia`: estilo Liquid Glass (referencia interna de glass).
- Mesa de revisión de cotización (`/cotizaciones/[id]/revision`, layout B, 2026-07-25): grid `lg:grid-cols-[1.2fr_1fr]` — chat a tres voces a la izquierda (`mesa-chat.tsx`), pestañas Rubros/Propuesta/Fotos a la derecha (`hoja-viva.tsx`, `propuesta-viva.tsx`, `fotos-panel.tsx`) con drag&drop global de fotos. Referencia para cualquier pantalla nueva que combine charla + datos vivos.

## Criterios de calidad

- Entregables de cliente (presupuestos, recibos, diagnósticos): dark premium,
  formato oficial ya definido (ver plantillas en `~/Documents/Plantillas/`).
- Referencia de vara alta para webs: igloo.inc (restricción, niebla, glow).
- Performance en mobile es parte del diseño: nada de animaciones que vibren
  o bloqueen (lección del orbital 18/07: RAF directo al DOM, no setInterval).
